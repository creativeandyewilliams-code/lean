# Background material (condition F: formal package)

Definitions and theorems (registered):
- First-order projection q_FO collapses latent states. **T-CONFLATE**: if
  q_FO(x)=q_FO(y) but the target verdict phi(x) != phi(y), then NO decoder that
  reads only q_FO is correct on both states.
- Reflection registers concepts-of-concepts and can NAME an unresolved residual,
  but does NOT increase cognitive order unless it supplies a new reusable,
  functionally non-equivalent composition that spans the space (order is the
  count of such spanning composition classes).
- Operation types: Register : signal -> concept (boundary); Recall : memory ->
  concept; L, G : concept -> concept (endomorphisms). **T-OP-NONREDUCTION**: no
  composition of only L and G equals Register or Recall (domain/type obstruction);
  a bridge would supply the missing primitive.
- Fragmentation: backlog U_{t+1}=max(0,U_t+A_t-S_t). After an order lift reverses
  an increasing backlog, persistent recurrence occurs under FIXED post-lift
  service, but PROPORTIONAL same-order service (service tracking arrivals with a
  positive margin) prevents persistent recurrence. (Executed five-regime result.)
- Great Filter claim ladder: **COR-GF-CNS** is a **GF-3** conditional result
  ("it would be a filter IF the mapping and hazard premises hold"); it is NOT a
  GF-6 identification of the observed Great Filter.
- External-premise register: "gravity <-> G" is an UNMEASURED EXTERNAL PREMISE
  (a candidate physical realization), not a kernel-proved theorem.
