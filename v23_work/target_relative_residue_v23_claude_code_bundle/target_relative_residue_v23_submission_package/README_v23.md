# Version 23 submission package

This package is written toward the explicit design hypothesis that a fresh carrier-complete assessment returns `GC_sub`. The expected result is not evidence. The initial actual status is `NE` until Claude Code performs an independent audit, supplies qpdf and Lean certificates, validates the complete trace, integrates the journal recommendation into the root, and applies the actual result.

Start with `00_CLAUDE_CODE_START_v23.md` or open the directory in Claude Code so `CLAUDE.md` is loaded.

`CarrierRepairClosureMatrix_v23.csv` maps the prior fresh-session objections and target-substitution failure to the Version-23 repairs and their independent closure conditions. `ExpectedGCDesignAssumptions_v23.md` states exactly what the expected `GC_sub` hypothesis requires.
