# Studia Logica Journal Profile Snapshot - Version 23

Accessed: 2026-07-26

- Scope: papers presenting original results on formal systems and employing formal tools of mathematics and broadly understood logic.
- Acceptance criterion: significant and original results concerning formal systems and their properties.
- General length: 8,000-10,000 words, including references, footnotes, tables, and figures.
- Maximum: 25 printed pages.
- Editable source files are required at submission and revision; LaTeX is accepted.
