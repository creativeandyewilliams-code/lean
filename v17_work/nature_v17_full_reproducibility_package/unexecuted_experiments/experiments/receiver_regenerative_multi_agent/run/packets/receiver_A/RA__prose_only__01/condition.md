# Prose-only condition

Semantic identity is constituted by target-relevant metric relations, typed interactions, relative position, boundaries, warrant, fitness, and continuation conditions. First-order projection can identify two latent states that require different target outputs; no decoder using only the collapsed projection can recover that distinction. Reflection exposes residuals but does not itself add a new reusable composition. Register has signal input, Recall has memory input, while L and G are conceptual endomorphisms. Cognitive order counts non-equivalent reusable spanning compositions. A valid lift adds a new non-equivalent spanning composition, expands the admissible operand domain, and reverses the current unresolved residual. Continued growth at fixed capacity can recreate backlog; scaling service or adding a further lift can prevent recurrence. The dynamical CNS bridge additionally requires contraction, closure, and invariance. Governance claims are participantwise, not aggregate. The Great Filter result reaches a conditional structural-filter level only when external branch, hazard, timescale, outcome, and residue premises are supplied. Physical-force assignments and claims about current AI remain external mappings.
