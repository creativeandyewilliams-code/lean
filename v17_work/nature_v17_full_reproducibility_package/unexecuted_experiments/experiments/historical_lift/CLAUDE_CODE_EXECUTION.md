# Historical order-lift execution

Before selecting cases, freeze `rubric.json`, candidate inclusion rules, evidence-source hierarchy, time window, and exclusion criteria. Build evidence dossiers with stable source citations. Generate blinded reviewer packets and use at least three fresh reviewers. Any rubric change invalidates all prior classifications and requires a full rerun. Disagreement is adjudicated by a typed evidence witness, not majority. Report `undetermined` when prior-unavailability, span, reuse, or operand expansion cannot be established.
