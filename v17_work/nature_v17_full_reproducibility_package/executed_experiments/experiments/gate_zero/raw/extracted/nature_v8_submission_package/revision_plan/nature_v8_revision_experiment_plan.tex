\begin{abstract}
This document replaces the v7 strategy and changes the stopping criterion of the revision program. The plan is not complete merely when its formal surface is internally consistent, when implementation appears more valuable than another revision, or when remaining edits are small. The required terminal property is \emph{propagation closure}: the Article, Supplement, canonical registry, implementation, tests, and experimental result signature must allow independent receivers to reconstruct and extend the same executable model without author repair. Formal closure, execution closure, and propagation closure are treated as distinct theorem and experiment targets.

The scientific object remains one paper and one coupled model. A single event-sourced generator acts on a stratified self-typing conceptual Functional State Space (FSS), participant-indexed three-dimensional fitness FSSs, typed signal carriers, bidirectional input/output transducers, active context, recoverable identities, inter-FSS couplings, certificates, governance rules, and one provenance-preserving residual ledger. Signal spaces are explicitly typed as carriers rather than FSSs, terminating the boundary construction. The conceptual internal basis spans transformations within the node domain maintained by Register and admissible composite promotion; it does not silently mint grounded identities. Create and composite promotion are one cross-linked candidate family until an experiment separates them. The canonical registry begins with the already discovered Store-omission and Destroy-status residuals instead of presenting reconciliation as complete.

The principal v8 addition is an integrated computer experiment designed to serve simultaneously as a scientific test, an implementation-conformance test, and an error-correcting transmission code for the model. Every result is generated by one executable transition engine. Experimental modules are read-only views over a common event log rather than locally reimplemented simulations. A preregistered library of plausible misreconstructions---including missing signal boundaries, collapsed Store/Recall, verdict-only $L/G$, connectivity-only $G$, primitive promotion, two-dimensional fitness, omitted governance, uncertified spanning, recursive signal-carrier regress, and split local generators---is assigned a predicted joint result signature. Test instances are selected to maximize the minimum distance between these signatures. The canonical model is supported only if one generator reproduces the full joint signature and the signature identifies it against both preregistered and held-out adversarial reconstructions.

The confirmatory spine has five linked results. First, boundary and internal function necessity are tested through target-pair nonfactorization witnesses with hidden-resource prohibitions. Second, paired lower-order-indistinguishable worlds test the phase transition produced only by recursive operand lift plus certified spanning and target-adequate Store/Recall. Third, participant-indexed three-dimensional fitness worlds test coherence-conditioned option monotonicity, governance-sensitive displacement containment, and preregistered valence inversion. Fourth, a correlation-aware real-trace experiment measures whether bounded projections preserve target-critical relations and whether the same bounded-registration law applies at trace, oversight, and signal interfaces. Fifth, blinded independent machine receivers reconstruct the model from nested artifact packages and execute held-out tasks. Propagation closure is a vector verdict over function inventory, layer structure, generator, interfaces, predictions, and novel extension, not a summary score that can hide a fatal contract inversion.

The plan specifies repository structure, state and event schemas, canonical function registry, deterministic replay, synthetic world generation, comparator and ablation library, candidate-model codebook, experimental phases, default sample sizes, randomization, primary estimands, statistical models, multiplicity control, robustness regimes, failure branches, historical comparison, Article and Supplement architecture, release gates, and the co-contraction loop between specification and implementation. It preserves the one participant-indexed fitness-displacement object, separates achieved-fitness movement from target revision, gives the path-fitness scalar an explicit defeat condition, retains structural reach separately from occupation, and precommits status-conditioned Article titles so historical uncertainty cannot contradict the title page.

The result sought is stronger than an interesting simulation. It is an exhibited invariant: one self-contained model, one implementation, one joint experimental signature, and a reconstruction package that independent receivers can regenerate, execute, and extend. The specification remains open only to revisions that reduce a demonstrated propagation-critical residual; additional surface that does not constrain operational reconstruction is not itself progress.
\end{abstract}

\section{Propagation closure and the experiment as a transmission code}

\subsection{Artifact package and reconstruction}

Let the transmitted package be
\begin{equation}
\Pkg=(A,S,\InvReg,C,D,T,\Codeword^{\ast}),
\end{equation}
where $A$ is the Article, $S$ the Supplement, $\InvReg$ the canonical registry and admissible projection table, $C$ the source code, $D$ data and event logs, $T$ the executable conformance and witness suite, and $\Codeword^{\ast}$ the observed joint result signature. A receiver $r$ under budget $B_r$ produces
\begin{equation}
\Mhat_r=\operatorname{Reconstruct}_r(\Pkg;B_r).
\end{equation}
The receiver has no author interaction, private chat history, or unstated definitions.

\subsection{Operational equivalence}

A reconstruction is equivalent to the canonical model $\Mstar$ when there exists an admissible renaming or presentation map that preserves: layer types; function contracts; signal/FSS domains and codomains; the coupled generator transition relation; three-dimensional fitness geometry; theorem dependencies; primary predictions; and held-out target behavior. Linguistic similarity is neither necessary nor sufficient.

\subsection{Propagation residual}

Define the typed propagation residual
\begin{equation}
\PropRes(r)=\left(\rho_{\Omega},\rho_{X},\rho_f,\rho_{I},\rho_{P},\rho_{E},\rho_{\rm fatal}\right),
\end{equation}
where the coordinates measure function-inventory/contract mismatch, space and layer mismatch, generator mismatch, interface mismatch, primary-prediction mismatch, held-out extension mismatch, and fatal contract inversions. A fatal inversion includes, for example, treating a signal carrier as an FSS, reversing Register and Express, collapsing Store into Recall, replacing global coherence with local validation, removing the target coordinate from fitness, or counting target revision as achieved improvement without governance.

The propagation verdict is a conjunction, not an average:
\begin{equation}
\operatorname{PropVerdict}(r)=\Pass
\end{equation}
only when every mandatory structural coordinate is exact up to admissible projection, $\rho_{\rm fatal}=0$, held-out deterministic prediction accuracy exceeds the preregistered threshold, and the receiver successfully implements the unseen extension target. A high mean score cannot compensate for a fatal type error.

\subsection{Joint experimental signature as an error-correcting code}

Let $\mathfrak M=\{M^{\ast},M_1,\ldots,M_J\}$ be the preregistered candidate reconstruction library. For a test suite $Q=\{q_1,\ldots,q_K\}$, each model predicts a ternary or quantitative codeword
\begin{equation}
\Codeword(M_j)=\bigl(q_1(M_j),\ldots,q_K(M_j)\bigr).
\end{equation}
The design algorithm selects tests to maximize the minimum pairwise distance
\begin{equation}
d_{\min}(Q)=\min_{j\ne k}d\bigl(\Codeword(M_j),\Codeword(M_k)\bigr),
\end{equation}
subject to compute and target-coverage budgets. The observed signature is decoded by likelihood under the measured stochastic error model. The experiment functions as a transmission code when the canonical codeword has positive separation from every target-different reconstruction and remains identifiable under the declared noise budget.

This is not evidence by definition. The candidate library is frozen before the confirmatory run; held-out adversarial variants are generated after test selection; the real-trace module supplies an external measured boundary; and a model that only fits the hand-selected candidates but fails held-out variants does not receive propagation closure.

\subsection{Freeze and revision rule}

The specification and implementation co-contract. An implementation failure may reveal a formal gap; a receiver reconstruction may reveal a propagation ambiguity; either can reopen the plan. A change is licensed only when it closes a typed formal, execution, or propagation residual. Additional theorem surface, examples, or modules that do not distinguish operational reconstructions do not count as closure.
\section{Complete coupled object and self-typing}

\subsection{Coupled generator}

Let $\mathfrak X=\{\C\}\cup\{\F_i:i\in I\}$ be the FSS instances inside the modeled FMI object. Each $X\in\mathfrak X$ has a signal space $\Sig_X$, an input transducer $\InOp_X$, an output transducer $\OutOp_X$, and an internal state. The complete state is
\begin{equation}
Z_t=\left(
\{X_t,\Sig_{X,t},\InOp_{X,t},\OutOp_{X,t}\}_{X\in\mathfrak X},
\Gamma_t,o_t,M_t,
\{\mathbf f_{i,t},\widehat{\mathbf f}_{i,t}\}_{i\in I},
\Lambda_t,e_t
\right),
\end{equation}
where $\Gamma_t$ is active context, $o_t$ the focal operand, $M_t$ the recoverable registry, $\mathbf f_{i,t}$ participant $i$'s realized three-dimensional fitness state, $\widehat{\mathbf f}_{i,t}$ its represented state, $\Lambda_t$ the typed coupling and residual ledger, and $e_t$ admitted environment state. The single generator is
\begin{equation}
\boxed{f:Z_t\rightarrow Z_{t+\Delta t}.}
\end{equation}
The universal boundary and domain-internal bases classify target-distinguishable contracts instantiated by transitions of this same generator. No external labeler supplies function type: function contracts, types, targets, budgets, and residuals are represented in the self-typing graph and tested by $L/G$.

\subsection{Strict stratified self-typing}

For order $n$ let $X_1=V^{(1)}$ and
\begin{equation}
X_{n+1}=\AdmSub_n(X_{\le n}).
\end{equation}
Type and boundary maps are strictly level-raising:
\begin{equation}
\tau_n:X_n\sqcup E(X_n)\rightarrow X_{n+1},\qquad
\beta_n:E(X_n)\rightarrow X_{n+1}.
\end{equation}
Level-$(n+1)$ objects may reference embedded lower-level objects, but impredicative self-application is inadmissible. The benchmark rejects any construction whose typing requires quantification over a universe containing the type object itself.

\subsection{Default admissibility predicate}

A finite conceptual composition $A$ belongs to $\AdmSub_n$ when: (i) target-relevant endpoints, types, and boundaries are contained or linked through typed interfaces; (ii) internal compositions are well-typed; (iii) $A$ preserves a declared target distinction; (iv) it is Store-feasible within budget with an explicit residual; (v) its local obligations can be submitted to $L$ and global obligations to $G$; and (vi) no stored decisive incoherence witness defeats it. The author may strengthen this predicate, but every replacement must itself be stored and assessed by $L/G$.

\subsection{Budgeted active context}

\begin{equation}
\Gamma_t=\{(c,a_t(c),r_t(c)):c\in M_t\},\qquad
\sum_c\kappa_t(c)r_t(c)\le C_t.
\end{equation}
Activation, represented resolution, complexity density, and budget are distinct. $C_t$, allocation policy, and compression schedule are typed control conditions unless an explicit submodel derives them. Residence time is derived conditional on these controls rather than assigned by a free decay coefficient.

\section{Universal signal space and bidirectional FSS transduction}

\subsection{Signal space}

For an FSS $X$, its signal space $\Sig_X$ is the typed carrier of functionally distinguishable boundary states and transitions through which $X$ can receive perturbations, observations, requests, or constraints and through which states of $X$ can become available to another FSS or environment. A signal is not an externally interpreted token by definition. Its admissible type, source, target, resolution, provenance, and relation to an FSS state are represented by the receiving or emitting FSS and by the boundary contract.

A signal carrier is structured but is not itself an FSS. It has no independent Store--Recall--$L$--$G$ basis, fitness controller, or signal boundary of its own. Signal-type objects occupy the boundary level immediately above the FSS states they encode. This type discipline terminates the boundary construction and prevents an infinite regress of signal spaces requiring further signal spaces. The carrier may be lossy, many-to-one, delayed, noisy, or budgeted. It is not identified with the target FSS; the relation is supplied only by explicit partial graph transformations.

\subsection{Universal boundary duality}

\begin{definition}[Input and output transduction]
For every observable interacting FSS $X$, define
\begin{equation}
\InOp_X:\D_{X}^{\rm in}\subseteq\Sig_X\rightharpoonup X,
\qquad
\OutOp_X:\D_{X}^{\rm out}\subseteq X\rightharpoonup\Sig_X.
\end{equation}
$\InOp_X$ accepts an admissible signal object or composition and emits an FSS state, relation, or update. $\OutOp_X$ accepts an admissible FSS state or composition and emits a signal object or composition. Both are typed graph operations generated by $f$.
\end{definition}

For conceptual space, use the names
\begin{equation}
\Register:=\InOp_{\C}:\Sig_{\C}\rightharpoonup\C,
\qquad
\Express:=\OutOp_{\C}:\C\rightharpoonup\Sig_{\C}.
\end{equation}
Register converts signal structure into concepts, relations, context updates, evidence, or obligations. Express converts concepts, relations, verdicts, plans, or other conceptual compositions into signal structure.

\subsection{Boundary contracts and residuals}

The duality is target-relative, not assumed lossless or exactly invertible. For an internal target $\Phi_X$ and signal target $\Psi_X$, define
\begin{align}
r_{\rm in}^{X}(s)&=d_X\!\left(\InOp_X(s),x_{\Phi}(s)\right),\\
r_{\rm out}^{X}(x)&=d_{\Sig_X}\!\left(\OutOp_X(x),s_{\Psi}(x)\right),\\
r_{\rm rt,X}(x)&=d_{\Phi_X}\!\left(\InOp_X(\OutOp_X(x)),x\right),\\
r_{\rm rt,\Sig}(s)&=d_{\Psi_X}\!\left(\OutOp_X(\InOp_X(s)),s\right),
\end{align}
where the comparison objects are supplied by a declared witness or decoder. A target-adequate round trip satisfies
\begin{equation}
\InOp_X\circ\OutOp_X\sim_{\Phi_X}\operatorname{id}
\end{equation}
on the expressible/recoverable class, and analogously in signal space where the signal target requires it. The two round trips need not have the same residual or domain.

\subsection{Necessity for observable interaction}

\begin{theorem}[Bidirectional signal-interface necessity]
Let $X$ be an FSS whose state can be changed by externally distinguishable conditions and whose state can produce externally distinguishable consequences. If no input transducer exists, there are signal states $s_1,s_2$ requiring distinct internal continuations that cannot be distinguished inside $X$. If no output transducer exists, there are internal states $x_1,x_2$ requiring distinct external consequences that cannot be distinguished in $\Sig_X$. Therefore both $\InOp_X$ and $\OutOp_X$ are necessary for the declared observable interacting target class.
\end{theorem}

The theorem is defeated by a two-way interaction target that is fully realized by one direction without hidden access to the other. A causally isolated object may omit the pair, but it is outside the declared class of observable interacting FSSs.

\subsection{Boundary and internal functions are distinct}

For every FSS:
\begin{equation}
\boxed{\Omega_X^{\partial}=\{\InOp_X,\OutOp_X\}.}
\end{equation}
For conceptual space:
\begin{equation}
\Omega_{\C}^{\rm int}=\{S,R,L,G\},\qquad
\Omega_{\C}^{\rm tot}=\Omega_{\C}^{\partial}\cup\Omega_{\C}^{\rm int}.
\end{equation}
For each participant fitness space:
\begin{equation}
\Omega_{\F_i}^{\rm int}=\{\Model,\Eval,\Stab,\Adapt,\Decomp,\Bridge\},\qquad
\Omega_{\F_i}^{\rm tot}=\Omega_{\F_i}^{\partial}\cup\Omega_{\F_i}^{\rm int}.
\end{equation}
The abstract FMI core therefore contains two universal boundary contracts, four conceptual internal contracts, and six fitness internal contracts. The same boundary types are realized separately at each FSS.

Store/Recall do not reduce the boundary pair. Store preserves an identity already inside $X$; Recall reactivates it. $\InOp_X$ creates or updates an internal state from a signal; $\OutOp_X$ makes an internal state available as a signal. A registered signal may subsequently be Stored, and a Recalled object may subsequently be Expressed, but these are compositions of distinct functions.

\subsection{Refinements and non-load-bearing naming questions}

An implementation may refine $\InOp_X$ into detect--discriminate--decode--register stages and $\OutOp_X$ into select--encode--emit stages. Such refinements become separate functions only if a matched-budget necessity witness shows that they are irreducible at the declared resolution. Create and Destroy are assessed independently: Create may be an internal graph expansion or part of transduction; Destroy may be deletion, contraction, suppression, or channel erasure. Neither is required to prove the bidirectional boundary theorem.

\subsection{Inter-FSS communication}

Communication from FSS $X$ to FSS $Y$ factors as
\begin{equation}
X\xrightarrow{\OutOp_X}\Sig_X\xrightarrow{T_{XY}}\Sig_Y\xrightarrow{\InOp_Y}Y,
\end{equation}
where $T_{XY}$ is a typed channel transformation carrying delay, corruption, budget, and provenance residuals. Regenerative transmission requires target-adequate output, channel preservation, and target-adequate input reconstruction. Exposure alone establishes none of these three.

\section{Typed functional dualities and conceptual basis}

\begin{definition}[Typed functional duality]
A typed functional duality for interface $\mathcal I$ is a pair $(u_{\mathcal I},v_{\mathcal I})$ whose domains, targets, budgets, evidence, residuals, and verdicts are internally represented; together the pair closes complementary obligations of the interface; neither can be replaced by the remaining basis under matched budget without merging a target-distinct witness pair; and their composition obeys a recovery, preservation, or correction contract. The pair need not consist of inverses or signed directions.
\end{definition}

\subsection{Registration--recovery duality}

Store registers an active concept or composition as one internally recoverable graph object:
\begin{equation}
S_\Phi:A_t\rightarrow M_{t+\Delta t},\qquad S_\Phi(x)=\widehat x.
\end{equation}
The stored object includes constituent relations, level-raised type bindings, boundaries, provenance, verdicts, and unresolved obligations required for valid reuse. Recall returns a stored identity to active contextual or focal status:
\begin{equation}
R_\Phi:M_t\rightharpoonup A_{t+\Delta t},\qquad R_\Phi(\widehat x)=x',\quad x'\sim_\Phi x.
\end{equation}
The target-relative recovery contract is
\begin{equation}
R_\Phi\circ S_\Phi\sim_\Phi\operatorname{id}.
\end{equation}
Store and Recall are write--recovery graph operations, not opposite signs on one coordinate.

\subsection{Local--global assessment duality}

For an assessable conceptual object $x$ with target $\Phi$, validation budget $B_L$, and coherence budget $B_G$:
\begin{equation}
L(x;\Phi,B_L)\in\{\valid,\invalid,\undetermined_{B_L}\},
\end{equation}
\begin{equation}
G(x;\Phi,B_G)\in\{\coherent,\incoherent,\undetermined_{B_G}\}.
\end{equation}
$L$ evaluates finite local proofs, reductions, certificates, and task executions. As a graph transformation it may contract an evidence subgraph to a locally valid object, attach an invalidity witness, or preserve an unresolved obligation. $G$ forms and traverses the target-relevant recursively composed support, restores omitted relations where admissible, preserves inherited obligations, and tests global coherence. As a graph transformation it emits a coherence verdict together with the support, defeating witness, or residual path that produced it. Both return stored verdict vertices linked to evidence, budget, provenance, residuals, and successor obligations; neither is merely an external label.

\subsection{Conceptual basis theorem target}

\begin{theorem}[Conceptual internal-duality basis]
If the self-typing conceptual object must preserve recoverable identity, reactivate registered identity, issue bounded local-validity verdicts, and issue recursive global-coherence verdicts; if the four necessity witnesses hold under matched budgets; and if all declared \emph{internal} conceptual transitions over the node domain maintained by Register and admissible composite promotion factor into finite compositions over the two dualities, then
\begin{equation}
\boxed{\Omega_{\C}=\{S,R,L,G\}}
\end{equation}
is the minimal conceptual internal basis within the declared target family and resolution. Together with $\Omega_{\C}^{\partial}=\{\Register,\Express\}$ it yields the total conceptual function family.
\end{theorem}

The theorem does not claim that the internal basis alone grounds new boundary identities or unitizes arbitrary distributed compositions. Register supplies grounded nodes from signal structure; the promotion construction supplies admitted composite operands; $G$ may form and restore internal support and relations among available objects. Necessity witnesses separate: recoverability without Store; active re-entry without Recall; bounded local validity without $L$; and target relations identical under every local quotient but distinct under recursive composition without $G$.

\subsection{Conditional interface-duality count}

If a functional object commits exactly $m$ target-irreducible binary interfaces, each requires one non-substitutable dual pair, every target-relevant transition factors over those pairs, and no additional interface survives internal completeness assessment, then the minimal basis has $2m$ functions. This conditional theorem replaces the v5 universal axis-count law.

\section{Three-dimensional fitness space and internal basis}

\subsection{Path-relative fitness}

For conceptual state $x$, target $\tau$, and budget $B$, let $\Pp_t(x,\tau)$ be the available reasoning paths. Fitness is the relative ability to traverse these paths and attain the same target. The primary object is the target-relative preorder $\succeq_{\tau,B}$ on path-equivalence classes. A scalar path-fitness coordinate $u_\tau$ is licensed only when an explicit order embedding exists at the declared resolution:
\begin{equation}
p_1\succeq_{\tau,B}p_2\Longleftrightarrow u_\tau(p_1)\ge u_\tau(p_2).

\subsection{Three-dimensional minimality and sufficiency}

Every two-coordinate projection merges a control-distinct pair. Omitting current fitness merges states requiring preservation versus repair; omitting target fitness merges adequate versus inadequate outcomes; omitting projected fitness merges actions with different next-step consequences. The full point determines
\begin{align}

\Delta\widehat f(a)&=f^{\rm proj}(a)-f^{\rm cur},\\
e^{\rm proj}(a)&=f^{\rm tar}-f^{\rm proj}(a),
\end{align}
which are sufficient for the declared minimal next-action controller subject to viability and coherence constraints. Recursive planning creates trajectories in the same $\mathbb R^3$; candidate actions are multiple points, uncertainty is a distribution over points, and multiple participants form a network of three-dimensional spaces rather than a participant-collapsed opaque carrier.

The planes $f^{\rm cur}=f^{\rm tar}$, $f^{\rm proj}=f^{\rm tar}$, and $f^{\rm proj}=f^{\rm cur}$ partition visually interpretable stability, adaptation, success, insufficiency, improvement, and harm regimes.

\subsection{Internal dualities from the three pairwise relations}

The current--target relation generates Stability/Adaptation: Stability preserves adequate traversal capacity under perturbation; Adaptation reconfigures when unchanged continuation is inadequate. \end{theorem}

A stable fourth coordinate or irreducible function reopens the model rather than being suppressed.

For each coordinate projection, construct two states that agree on the retained coordinates and differ on the omitted coordinate while requiring different verdicts.

\begin{enumerate}

\item \textbf{Omit target fitness.} Fix $f^{\rm cur}=0.4$ and $f^{\rm proj}=0.6$. Let one target be $0.5$ and another $0.8$. The same action is sufficient in the first state and insufficient in the second. The target verdict does not factor through $(f^{\rm cur},f^{\rm proj})$.

\subsection{Branching and asymmetry}

For a homogeneous acyclic approximation, the expected number of reliable descendants at depth $d$ may scale as
$(b\ell)^d$. Exponential growth occurs only when $b\ell>1$ and terminal values do not decay fast enough to cancel it.
Both $b$ and $\ell$ should be derived from the certified trajectory process where possible. They are not generator dials
used to assign amplification.

\subsection{Distributional reporting}

Dependency outcomes are likely correlated and heavy-tailed. Report the full distribution, quantiles, positive-value
probability, participant-viability violation probability, and tail loss. Means remain secondary summaries.

\section{Primary comparison classes}

\subsection{Capacity innovations}

These increase compute, memory, bandwidth, participants, or search while preserving operand order.

\subsection{Representation and certification innovations}

These improve projection adequacy, mechanistic evidence, verification, or bridge reliability without creating a new
operand order.

\subsection{Governance innovations}

These expand fitness support or reduce influence concentration without changing reasoning order.

\subsection{Order-lifting innovation}

The CNS changes the admissible operand and operator class and may recursively generate additional operators.

\subsection{Composite innovations}

Test combinations such as CNS plus participant-complete governance, CNS plus centralized governance, compute plus
certification, and decentralization plus first-order reasoning. This reveals complementarity and sign inversion.

\section{Fitness governance and the sign of importance}

\subsection{Participant-indexed fitness}

For participant $i$, let $\F_i\subseteq\mathbb R^3$ be the current--target--projected fitness space and $A_i\subseteq\F_i$ its continuation or
viability region. The collective state evolves under
\begin{equation}
T_{\mathrm{col}}:\C_{\mathrm{col}}\times\prod_{i=1}^{N}\F_i\to\C_{\mathrm{col}}.
\end{equation}

\subsection{Exact support and influence concentration}

For $S\subseteq\{1,\ldots,N\}$, let $q_S$ project onto fitness coordinates in $S$. Define
\begin{equation}
k_\ast
=
\min\left\{|S|:T_{\mathrm{col}}=\widehat T_S\circ(\operatorname{id},q_S)\right\}.
\end{equation}

If normalized counterfactual influence is $w_i$, define
\begin{equation}
N_{\mathrm{eff}}=\frac{1}{\sum_iw_i^2},
\qquad
D_{\mathrm{eff}}=\frac{N_{\mathrm{eff}}-1}{N-1}.
\end{equation}

\subsection{Participant-complete viability}

The primary decentralized governance rule should be:
\begin{equation}
\gamma\text{ admissible}
\Longleftrightarrow
f_i(\Real(\gamma))\in A_i\quad\forall i.
\end{equation}
A scalar objective may rank trajectories only inside the jointly viable set. This prevents a high average score from
masking terminal loss to one participant class.

\subsection{Importance allocation}

For each innovation $a$, report:
\begin{itemize}
\item total importance magnitude;
\item participant-wise importance vector $\mathbf J_i(a)$;
\item minimum participant importance;
\item number/fraction of participants whose viability is reduced;
\item governance support $k_\ast$ and $N_{\mathrm{eff}}$;
\item whether high aggregate importance is produced by transferring loss to omitted participants.
\end{itemize}

This turns governance into the sign-allocation layer of the importance theorem.

\section{Target adequacy, certified bridges, and residual gating}

\subsection{Target adequacy}

Let $\Phi:X\to\{\safe,\unsafe\}$ and $q:X\to Z$. Exact adequacy requires
\begin{equation}
q(x)=q(y)\Longrightarrow\Phi(x)=\Phi(y).
\end{equation}
For a stochastic channel, use $Q(z\mid x)$ and report Bayes decodability or a proper score.

The evaluator must return
\begin{equation}
\{\safe,\unsafe,\undetermined\}.
\end{equation}
Missing information must not be converted into false safety.

\subsection{Certified bridges}

Each bridge object should include:
\begin{equation}
b=(s,t,\tau,\beta,\kappa,\epsilon,r),
\end{equation}
where $s,t$ are source and target objects, $\tau$ is transformation type, $\beta$ contains boundary/admissibility
conditions, $\kappa$ is a certificate, $\epsilon$ is a semantic/evaluator equivalence object, and $r$ is a typed residual
vector.

\subsection{Reliable reach}

Define reliable reach using only paths whose certificates and residuals satisfy declared thresholds:
\begin{equation}
R_{\cert}^{(n)}
=
\nu_n\left(\{y:\exists\text{ certified admissible path }x\rightsquigarrow y\}\right).
\end{equation}
Nominal reach should be reported only beside reliable reach.

\subsection{Residual as a gate, not an arbitrary additive scalar}

Residuals may be typed:
\begin{equation}
r=(r_{\mathrm{semantic}},r_{\mathrm{boundary}},r_{\mathrm{certificate}},r_{\mathrm{evaluator}},r_{\mathrm{dynamic}},r_{\mathrm{fitness}}).
\end{equation}
A path contributes to importance only when the relevant coordinates fall within declared tolerances or when a
justified typed aggregation rule establishes admissibility. Do not sum heterogeneous residuals without a common
ordered structure or justified scalarization.

\section{Civilizational survival leverage}

\subsection{Hazard intensity}

Let $I_a(t)$ be conceptual/innovation trial intensity, $h_a(t)$ the density of paths entering a terminal-risk class,
and $s_a(t)$ the probability that such a conceptual path is realized. Define
\begin{equation}
\lambda_a(t)=I_a(t)h_a(t)s_a(t),
\qquad
\Lambda_a(T)=\int_0^T\lambda_a(t)\,dt,
\qquad
S_a(T)=e^{-\Lambda_a(T)}.
\end{equation}

\subsection{CNS survival leverage}

The survival component of importance is
\begin{equation}
\Delta\Lambda_{\CNS}(T)=\Lambda_{\base}(T)-\Lambda_{\CNS}(T).
\end{equation}
A positive value means the CNS reduces cumulative terminal hazard; a negative value means it increases it.

Because a CNS can increase $I(t)$ while reducing $h(t)$ or $s(t)$ through better recognition and control, the sign is
not predetermined. This interaction is scientifically central. A CNS can be both the greatest capability accelerator
and the greatest safety intervention, or the greatest risk amplifier, depending on governance and certification.

\subsection{Topological and measure-theoretic regimes}

Retain two distinct Great Filter mechanisms:
\begin{enumerate}
\item \textbf{Topological cut-set regime}: every path to a capability region intersects a terminal-risk class.
\item \textbf{Measure-theoretic regime}: cumulative hazard diverges because $\Lambda(\infty)=\infty$.
\end{enumerate}
Neither follows from conceptual-space existence alone. The benchmark supplies conditional synthetic realizations,
not an empirical extinction estimate.



\section{Coherent option selection and valence inversion}

\subsection{Participantwise option-monotonicity lemma}

Let $O_b\subseteq O_a$ be certified option sets, let $v_i(o)$ be participant $i$'s realized target-relative fitness value, and let $\widehat v_i(o)$ be the represented value used by the selector. Assume, on every option actually compared,
\begin{equation}
|\widehat v_i(o)-v_i(o)|\le\epsilon_i.
\end{equation}
Let the selector be $\delta_i$-approximate for the represented order:
\begin{equation}
\widehat v_i(\operatorname{Sel}(O))\ge \sup_{o\in O}\widehat v_i(o)-\delta_i,
\end{equation}
and let the admissibility gate preserve every option in the comparator set $O_b$. Then
\begin{equation}
\boxed{v_i(\operatorname{Sel}(O_a))\ge \sup_{o\in O_b}v_i(o)-(2\epsilon_i+\delta_i).}
\end{equation}

\textit{Proof.} The selected option is within $\delta_i$ of the best represented option in $O_a$, hence within $\delta_i$ of the represented value of the best realized comparator option in $O_b$. Converting the selected represented value to realized value loses at most $\epsilon_i$, and converting the comparator realized value to represented value loses at most another $\epsilon_i$. Combining the inequalities yields the bound.

Strict improvement is licensed when an admitted new option has a realized margin above the best comparator exceeding $2\epsilon_i+\delta_i$ and is selected under the declared rule. For several participants, this statement is applied participantwise. A collective conclusion requires a stored governance rule defining admissibility, trade permissions, and selection. Pareto containment requires the participantwise inequalities; scalar aggregate containment is asserted only when governance generates the scalarization.

\subsection{Distributional extension}

The pointwise lemma does not by itself imply stochastic dominance. A stochastic claim requires an explicit common coupling or monotone transition-kernel condition, participantwise error bounds holding almost surely or with declared probability, and a stated dominance order. The benchmark therefore reports pointwise bounds, probability of participantwise violation, quantiles, tail loss, and stochastic-dominance tests separately.

\subsection{Valence inversion outside the guarantee}

Outside the lemma's premises, an option superset can be worse. A constructive witness adds an option with highest represented value and lowest realized value. Inversion can arise from bounded error when improvement margins lie inside the coherence budget, an unsound admissibility gate, Modeling error, Evaluation error, Bridging error, realization noise, participant conflict, or a governance rule that omits a participant. Unbounded Evaluation residual is one sufficient construction, not the exact or only failure regime. The positive and negative valence results are two regimes of the same capability-expansion object.

\section{Self-contained theorem package v8}

The theorem package is grouped by causal role rather than expanded one theorem per diagnostic. Every final theorem states domain, target, budget, resolution, exactness status, executable witness, and defeating counterexample.

\begin{enumerate}
\item \textbf{Signal-carrier and bidirectional-transduction theorem.} Signal spaces are typed non-FSS carriers; every observable interacting FSS requires target-distinguishable input and output transduction, with exact or bounded round-trip contracts.
\item \textbf{Invariant registry theorem.} Every load-bearing presentation, diagram, code module, and experiment inventory is an admissible projection of one exhibited registry under a preregistered map family; unreconciled contract inversion is a global incoherence witness.
\item \textbf{Conceptual internal-basis theorem.} Given a node domain maintained by Register and admissible promotion, the registration--recovery and local--global assessment dualities yield the minimal internal basis $\{S,R,L,G\}$ within scope.
\item \textbf{Three-dimensional fitness-control theorem.} Current, target, and action-conditioned projected fitness are independently necessary and jointly sufficient for the declared minimal controller; their pairwise relations yield the six internal fitness functions under the stated factorization conditions.
\item \textbf{Internal completeness theorem.} Basis completeness is a stored conceptual object assessed by Store, Recall, $L$, and $G$; it is complete only for a declared registry, target family, budget, and resolution.
\item \textbf{Promotion, order-lift, and span theorem family.} Create/promotion is tested as one candidate family; lower-order projections can agree while lifted targets differ; lift and span are independent; their certified conjunction strictly increases reliable reach on at least one nonfactorizing family.
\item \textbf{Residual and global-coherence theorem.} Signal, identity, assessment, fitness-control, channel, certificate, governance, and realization residuals are stored with provenance. Global coherence requires closure, safe discharge, or certified contraction to closure, not mere nonincrease.
\item \textbf{Bounded-registration theorem.} Exact and approximate target recovery factor through a bounded projection only under the stated sufficiency condition; structural reach is distinct from occupation and available traces can be inadequate even when local verdicts remain accurate.
\item \textbf{Coherent option and displacement theorem family.} Capability containment plus participantwise bounded model/selection error yields the $2\epsilon+\delta$ option bound and, with the required coupling assumptions, displacement containment. Outside the guarantee, explicit valence inversions exist.
\item \textbf{Decision, propagation, and survival theorem family.} Decision asymmetry, regenerative signal transmission, and survival leverage are derived views of the same terminal consequence process and require measured or bounded branching, reliability, timing, realization, and hazard bridges.
\item \textbf{Experimental model-identification theorem.} If the selected joint signature has minimum distance exceeding twice the declared observation-error radius, nearest-valid-codeword decoding uniquely identifies the canonical model within the preregistered candidate class.
\item \textbf{Propagation-closure theorem target.} If the artifact package exhibits the registry, generator, codeword, conformance suite, and held-out extension contracts, and if competent receivers reconstruct models within the declared residual bounds without author repair, then the model is propagation-closed for that receiver class, package, budget, and resolution.
\item \textbf{Conditional historical maximality theorem.} If the preregistered audit finds no prior innovation matching the full operand, span, recovery, certification, governance, signal-realization, and displacement profile, the first globally coherent CNS occupies the highest supported historical importance class.
\end{enumerate}

\section{Integrated Single-Generator Propagation Experiment}

\subsection{Purpose}

The Integrated Single-Generator Propagation Experiment (ISGPE) is the primary computational study. Its purpose is not to accumulate independent demonstrations. It asks whether one canonical model generates a linked set of predictions that jointly distinguish it from capacity-only comparators and from plausible partial or distorted reconstructions, and whether the resulting artifact package causes independent receivers to recover and extend that model.

\subsection{Five-result confirmatory spine}

The Article's confirmatory spine is limited to five linked results:
\begin{enumerate}
\item \textbf{Function and boundary necessity.} Proper subsets or type-inverted versions of the universal boundary pair, conceptual internal basis, and fitness internal basis fail designated target-pair witnesses under matched resources and no hidden oracle support.
\item \textbf{CNS phase transition.} Recursive operand lift plus certified spanning, target-adequate Store/Recall, and grounded Register/Express produce a nonfactorizing increase in certified reach and recursive reuse that matched compute, population, communication, certification-only, lift-only, and span-only interventions do not reproduce.
\item \textbf{Coherence-conditioned importance.} In the residual-closed, participant-complete regime, the larger certified option set yields participantwise displacement containment within the stated coherence budget; certificate, model, signal, or governance failures produce preregistered inversion witnesses.
\item \textbf{Bounded observability.} Synthetic and real externally available reasoning records show when target-critical relations fail to factor through finite projections; correlation and redundancy modify the pure conjunction law but do not erase the bounded-registration target.
\item \textbf{Propagation closure.} The full package identifies the canonical model against preregistered and held-out reconstructions and enables independent receivers to reconstruct, execute, and extend it more reliably than text-only and structurally ablated packages.
\end{enumerate}
All other results are mechanism diagnostics, robustness tests, historical localization, or derived consequences of this spine.

\subsection{Non-negotiable single-model rules}

\begin{enumerate}
\item There is one transition function in the repository:
\begin{equation}
\operatorname{step}(Z_t,a_t,\xi_t)\mapsto (Z_{t+1},E_{t:t+1}),
\end{equation}
where $\xi_t$ is a seeded stochastic input and $E_{t:t+1}$ the event batch.
\item Every module is a pure read-only query over the canonical state or event log. A module may not update state, invent a local operator, maintain an unregistered cache, or replace the generator with a fitted surrogate for primary results.
\item Every event records registry version, operator identifier, typed inputs and outputs, pre/post state hashes, budget consumption, residuals, provenance, random seed, and target object.
\item Every intervention differs from the baseline by a versioned patch to registry-enabled functions, boundary conditions, or resources. It does not fork the model definition.
\item All paired comparisons use common random numbers and identical generated worlds. Resource matching is performed on executed operations, memory, communication, and validation work recorded by the log.
\item Every result row carries the canonical model hash. A mixed-hash primary result is invalid.
\item All local inventories, legends, and output schemas are generated from $\InvReg$. Hand-maintained duplicate function lists are forbidden.
\end{enumerate}

\section{Synthetic world and target generator}

\subsection{Stratified self-typed conceptual worlds}

The primary synthetic world is a finite stratified typed multigraph. Level one contains grounded concept nodes and typed relations. For $n\ge1$,
\begin{equation}
X_{n+1}=\{\rho_n(A):A\in\AdmSub_n(X_{\le n})\},
\end{equation}
where $\AdmSub_n$ is the frozen admissibility predicate and $\rho_n$ is either the composite Create/promotion candidate or the primitive comparator. Types are strictly level raising. Each world includes local regions, sparse target-relevant cross-region relations, admissible and inadmissible composite operands, decoy bridges, and certificate objects.

\subsection{Paired nonfactorizing worlds}

For every order $n$, generate pairs $(W^0,W^1)$ such that their complete order-$n$ observable projections are identical:
\begin{equation}
q_n(W^0)=q_n(W^1),
\end{equation}
but an order-$(n+1)$ target differs:
\begin{equation}
\Phi_{n+1}(W^0)\ne\Phi_{n+1}(W^1).
\end{equation}
Targets include higher-order relation presence, admissible composite classification, global support membership, participant consequence, and certificate-valid path existence. Leakage tests train flexible lower-order decoders; any above-chance recovery beyond the preregistered tolerance invalidates the pair.

\subsection{Signal carriers and channels}

Each grounded input and propagated output passes through a typed carrier. Primary channel families include exact, erasure, substitution, many-to-one compression, bounded-capacity, delayed, and correlated-noise channels. Register and Express can be exact, lossy, ambiguous, or target-aware. Channel parameters are instance conditions, not model-derived values. Round-trip targets are exact identity, relation preservation, verdict preservation, or action preservation depending on the task.

\subsection{Active context and recoverable identity}

The active-context allocation satisfies
\begin{equation}
\sum_{c\in\Gamma_t}\kappa(c)\operatorname{res}_t(c)\le C_t.
\end{equation}
Store fidelity controls target-relative preservation of identity and load-bearing relations; Recall fidelity controls reactivation; both are implemented through the same generator and measured through recovery residuals. Compression may lower resolution but cannot be relabeled as successful Store if the target is no longer recoverable.

\subsection{Three-dimensional participant fitness worlds}

The primary synthetic target families have known order embeddings $u_{i,\tau}$. Each participant has
\begin{equation}
\mathbf f_{i,t}(a)=\left(f^{\rm cur}_{i,t},f^{\rm tar}_{i,t},f^{\rm proj}_{i,t+1\mid a}\right)\in\mathbb R^3,
\end{equation}
with realized successor $f^{\rm cur}_{i,t+1}$. World generators independently vary current adequacy, target, projected action effect, model error, selection error, viability region, participant conflict, and governance support. Adversarial worlds omit one coordinate, add an alleged fourth coordinate, or use a non-embeddable partial order.

\subsection{Decision and survival layers}

Unique terminal consequences are attached to certified trajectories. Branching, reliability, decision windows, reversibility, realization, and hazard bridges are generated and logged. Values are not assigned to paths independently; terminal participant displacement induces the decision view. Positive, neutral, and inversion hazard regimes are generated explicitly so survival is never predetermined by the CNS label.

\subsection{Primary world counts}

The default confirmatory design, frozen after a runtime-only pilot, is:
\begin{itemize}
\item 10,000 deterministic paired witness instances distributed across boundary, conceptual, fitness, and order-nonfactorization families;
\item 1,024 Sobol-sampled integrated boundary regimes plus 64 preregistered corner regimes;
\item nine interventions applied to every regime with 32 common-random-number trajectory replicates and horizon 256, yielding 313,344 primary stochastic trajectories;
\item primary participant count $N=16$, with robustness at $N\in\{4,64,256\}$;
\item order depth $n\in\{1,2,3,4\}$ and graph sizes chosen so exact reach is available for the smaller half and Monte Carlo reach for the larger half.
\end{itemize}
The runtime pilot may reduce or increase replicate counts before any outcome is inspected; the final counts and power/Monte Carlo precision calculations are preregistered.

\section{Phase 1: integrated CNS phase-transition experiment}

\subsection{Primary construction}

For every paired world, each intervention receives the same order-$n$ projection, signals, resource budget, random stream, and target. The target may depend on an order-$(n+1)$ relation unavailable to every lower-order decoder. The full CNS must construct the admissible composition, validate and Store it, Recall it as an operand, span the lifted domain with certified bridges, and Express a target-relevant result through the declared signal chain.

\subsection{Primary estimands}

The principal phase-transition estimands are:
\begin{align}
\Delta R_{\rm cert}&=R_{\rm cert}^{\CNS}-R_{\rm cert}^{\rm comparator},\\

The confirmatory interaction is lift $\times$ span $\times$ certification, with Store/Recall recovery as a gating mediator rather than a separately added value coordinate.

\subsection{Support rule}

The phase-transition claim is supported only if:
\begin{enumerate}
