# v15 manuscript sources (Article and Supplement)

`nature_article_v15.pdf` and `nature_supplement_v15.pdf` in the repository
root were originally supplied only as LibreOffice-produced PDFs, with no
editable source. To apply the v15 revision required by
`v15_open_gate_closure_note.pdf` (and consistent with
`nature_v15_revision_experiment_plan.md`), the manuscripts were transcribed
into the editable markup files here and re-rendered to PDF.

## Files

- `nature_article_v15.mns` — Article source (line-oriented markup).
- `nature_supplement_v15.mns` — Supplement source.
- `figures/recurrence_backlog.png`, `figures/recurrence_regions.png` —
  direct-recurrence figures, generated by `../tools/recurrence_figures.py`.
- `../tools/render_manuscript.py` — the markup-to-PDF renderer (reportlab,
  FreeSerif for full Unicode math coverage).

## Rebuild

```
python3 tools/recurrence_figures.py manuscript_src/figures
python3 tools/render_manuscript.py manuscript_src/nature_article_v15.mns \
    nature_article_v15.pdf "Nature Communications submission draft - v15 | Article"
python3 tools/render_manuscript.py manuscript_src/nature_supplement_v15.mns \
    nature_supplement_v15.pdf "Nature Communications submission draft - v15 | Supplementary Information"
```

## Revisions applied in this version

Article
1. The registered-but-unexecuted direct recurrence statement is replaced by a
   concise report of the executed five-regime recurrence result, labelled
   synthetic and model-relative.

   fail-closed negative audit (v8 executable lineage absent).

   results, not v15-audited.

   no-sorry / no-custom-axiom scan) but not kernel-checked; a lexical scan is
   not a kernel proof.
5. Receiver propagation and external mappings are kept explicitly open.

Supplement
